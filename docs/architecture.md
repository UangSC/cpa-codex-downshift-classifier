# 架构与扩展

插件包含三个运行边界：CPA 加载的原生桥接层、Go 检测服务，以及同源 React 页面。后台服务是任务和持久化状态的权威来源，浏览器不执行模型推理。

```text
React 页面 → 插件管理 API → 分类服务 → CPA 官方宿主与管理 API
                              ↓
                       插件独立 state.json
```

## 原生桥接：cmd/downshift

- `main.go` 实现 C ABI 导出、宿主回调与缓冲区释放。
- `plugin.go` 实现插件生命周期、能力注册与元数据。
- `config.go` 解析服务器端配置标量，生命周期层负责建立适配器和分类服务。
- `management.go` 注册固定管理路由，处理认证后的请求并提供嵌入页面资源。

管理密钥只在服务器端使用，不投影到页面快照。异步任务不保存入站请求的临时宿主回调 ID。

## CPA 适配：internal/cpa

适配器负责官方接口协议和认证边界，不决定凭证分类。

- 凭证模块合并宿主身份、运行时状态、官方模型目录和被动额度数据。
- 路由模块通过官方字段 PATCH 修改前缀或优先级，保留其它凭证字段。
- `probe.go` 锁定 `auth_id` 和 `forced_provider: codex`，调用宿主模型流接口。
- `response_stream.go` 同时处理完整 SSE、字节分片、宿主去掉换行后的逐行事件和裸 JSON；完整终态及有效文本才可形成回答。
- `request_headers.go` 校验头覆盖并维护专用动态映射；认证、账号、路由、会话和传输头由 CPA 管理。

新 CPA 接口优先在此包中实现，再通过分类服务的适配器边界使用。不要在前端自行读写认证文件或直连模型上游。

## 业务服务：internal/classifier

- `service.go` 管理服务生命周期、状态加载与迁移。
- `candy.go` 保存糖果题和数字匹配规则。
- `tasks.go` 管理任务入队、并发、取消与进度。
- `inspection.go` 执行单凭证检测、有限重试、结果判定与分类同步。
- `settings.go`、`routing.go` 处理设置和凭证路由操作。
- `state.go` 负责原子保存和状态辅助函数；`snapshot.go` 生成页面所需的真实状态。
- `schedule.go`、`consent.go` 管理定时计划与配置确认指纹。
- `exclusions.go` 管理不参与巡检的凭证，保留原分类与历史。
- `http.go` 处理业务 API，`types.go` 定义持久化与页面契约。

新增检测方法时，应同时明确题目、答案判定、重试条件、历史证据以及计划授权指纹。新参数不能只保存在页面草稿中；后台每轮任务应冻结配置供全部重试复用。

## 页面：src

- `api/` 负责同源请求、认证和类型转换。
- `store/actions.ts` 提交、同步或取消真实后台操作；其它状态模块维护快照、排除池和设置草稿。
- `views/` 组织页面，`components/` 提供业务组件，`components/ui/` 按职责组织通用控件。
- `inspection/` 描述可展示的检测方式与题数，`lib/` 保存格式化、分页、路由和交互纯函数。
- `styles/` 使用共享主题变量和按功能组织的样式。

添加页面操作时，先扩展 `api/` 契约，再由动作层管理等待、失败与刷新，最后在组件中展示。异步返回不得覆盖更新后的来源或用户仍在编辑的设置草稿。

## 保持的约束

- 不修改 CPA 内核，不绕过宿主认证和既有代理。
- 权重只继承 CPA 值，任何策略都不写权重。
- 外部配置和插件预期有差异时显示待同步，不把期望值冒充为已生效。
- 认证或额度错误不等于能力降档，部分流和空回答不等于有效结果。
- 持久化不存上游认证令牌，错误消息不返回原始秘密。
